Zafe 개인 사진 보관함에서 할 수 있는 일

사진, 동영상, 파일, 메모를 Face ID와 비밀번호 보호 백업으로 기기 안에서 안전하게 보관하세요.

무료 버전에는 앨범 1개, 최대 10개 항목, Secure Notes, 자동 잠금, Face ID 또는 암호가 포함됩니다.

Pro는 한 번의 구매로 사용할 수 있습니다.

미디어·파일·메모의 본문 데이터와 썸네일은 기기에서 CryptoKit AES-GCM으로 암호화됩니다. 이름, 원래 파일명, 날짜, 선택적 좌표 같은 SwiftData 메타데이터는 iOS Data Protection으로 보호되며 앱 수준 AES 암호화라고 표현하지 않습니다.

Zafe에는 개발자 운영 서버가 없습니다(no developer-operated server). Pro 권한을 확인하거나 구매 화면을 열고 구매 또는 복원할 때 Apple StoreKit은 현지 가격 표시와 권한 처리를 위해 제품 ID, storefront, 구매/복원 거래 데이터를 받습니다. Apple은 자사 정책에 따라 보관합니다. Zafe는 로컬 권한 상태만 저장하며 개발자는 카드 정보를 받거나 이 데이터를 공유하지 않습니다.

침입자 카메라와 위치는 기본적으로 꺼져 있고 각각 명시적 동의가 필요합니다. 촬영을 켠 뒤 선택적 위치는 iOS Location Services의 좌표를 로컬 로그에 추가합니다. 위치가 있는 기록을 열면 CLGeocoder가 장소명을 받기 위해 좌표를 Apple에 보냅니다. Apple Maps는 사용자가 ‘지도에서 열기’를 누른 경우에만 선택 좌표를 받습니다. 좌표는 기록 또는 앱을 삭제할 때까지 로컬 SwiftData에 남으며 개발자나 다른 곳으로 전송되지 않습니다.

주요 기능

  • 앨범과 항목을 무제한으로 보관
  • 전용 암호로 여는 보조 안전 금고(데코이 금고)
  • 침입자 캡처는 기본적으로 꺼져 있으며, 사용자가 명시적으로 켜고 카메라 권한을 허용한 경우에만 잘못된 암호 입력 시 사진, 시간, 선택적 위치를 기록
  • 모두 Zafe 브랜드가 명확히 표시된 대체 앱 아이콘

자주 묻는 질문

계정을 만들어야 하나요?

아닙니다. 제품 페이지에는 계정, 회원가입, 로그인이 없다고 안내되어 있습니다. 설치한 뒤 바로 쓰시면 됩니다.

구독형인가요?

아닙니다. 제품 페이지에는 정기 결제 구독이 아니라 한 번만 결제하는 방식으로 안내되어 있습니다. 결제 전에 App Store 제품 페이지에서 무엇에 대한 요금인지 다시 확인할 수 있고, 현재 사용 중인 구독은 '설정 → (본인 이름) → 구독'에서 볼 수 있습니다.

카메라 미리보기가 까맣게 나옵니다

'설정 → 개인정보 보호 및 보안 → 카메라'에서 해당 앱이 켜져 있는지 확인하세요. 이미 켜져 있다면 카메라를 계속 붙잡고 있을 수 있는 다른 앱(Zoom, FaceTime, 다른 스캐너 앱 등)을 닫은 다음, 이 앱을 강제 종료했다가 다시 여세요.

Face ID로 앱 잠금이 안 풀립니다

'설정 → Face ID 및 암호 → 기타 앱'에서 해당 앱이 켜져 있는지 확인하세요. Face ID가 계속 실패하면 iOS가 기기 암호 입력으로 넘어갑니다. 이는 앱 설정이 아니라 iOS의 동작입니다.

내보낸 파일은 어디에 저장되나요?

내보내기는 iOS 공유 시트를 거치므로 저장 위치는 직접 고른 곳이 됩니다. 파일 앱(나의 iPhone 안 또는 iCloud Drive), 메일, 메시지, 다른 앱 등입니다. 나중에 파일을 못 찾겠다면 파일 앱을 열고 '최근 항목'을 확인해 보세요.

결제했는데 잠긴 버전 그대로예요

1회성 구입은 구입에 사용한 Apple 계정에 연결됩니다. '설정 → (본인 이름) → 미디어 및 구입 항목'에서 같은 계정으로 로그인한 뒤, 앱에 복원 항목이 있으면 실행하거나 App Store의 '구입 항목'에서 앱을 다시 설치해 보세요. 가족 구성원 계정을 포함해 다른 Apple 계정으로 구입한 항목은 나타나지 않습니다.

iPhone을 바꿨는데 다시 결제해야 하나요?

아닙니다. 새 기기에서 같은 Apple 계정으로 로그인한 뒤 앱을 다시 내려받으세요. 구입 내역은 기기가 아니라 계정에 남습니다.

환불은 어떻게 요청하나요?

App Store에서 구입한 항목의 환불은 개발자가 아니라 Apple이 처리합니다. reportaproblem.apple.com에 로그인해 해당 구입 항목을 찾은 뒤 '환불 요청'을 선택하세요. 저희가 App Store의 환불 결정을 대신 처리하거나 앞당기거나 뒤집을 수는 없지만, 무엇이 문제였는지 알려주시면 고치는 데 쓰겠습니다.

앱과 저장된 데이터를 모두 지우려면 어떻게 하나요?

앱 아이콘을 길게 누른 뒤 '앱 제거' → '앱 삭제'를 선택하세요. iOS에서 앱을 삭제하면 그 앱의 샌드박스가 함께 사라지므로, 기기에 저장돼 있던 문서와 설정도 같이 지워집니다. 남기고 싶은 것은 먼저 내보내 주세요. 무엇을 어디에 저장하는지는 개인정보 처리방침에 적혀 있습니다.

최신 버전인지 확인하려면?

App Store를 열고 오른쪽 위 프로필 사진을 누른 다음, 업데이트 대기 목록을 아래로 당겨 새로 고치세요. 목록에 앱이 보이면 '업데이트'를 누르면 됩니다. '설정 → App Store → 앱 업데이트'를 켜 두면 자동으로 최신 상태가 유지됩니다.

Zafe 개인 사진 보관함은 어떤 기기와 iOS 버전이 필요한가요?

App Store 제품 페이지를 확인해 주세요. 호환성, 용량, 지원 언어는 그곳의 '정보' 항목이 언제나 가장 정확하고 최신입니다.

문제 해결

앱이 안 열리거나 열자마자 종료됩니다

먼저 강제 종료해 보세요. 화면 아래에서 위로 쓸어올린 뒤 잠시 멈추고, 앱 카드를 위로 밀어 닫습니다. 그런 다음 다시 열어 보세요. 그래도 종료된다면 기기를 재시동하세요. 일시적인 실행 오류는 대부분 이 단계에서 해결됩니다.

느리거나 큰 작업에서 멈춥니다

'설정 → 일반 → iPhone 저장 공간'에서 남은 용량을 확인하세요. 여유 공간이 1GB 아래로 내려가면 iOS 동작이 불안정해지고, 파일을 쓰는 기능(내보내기, 스캔, 이미지 처리)이 가장 먼저 영향을 받습니다. 백그라운드에서 돌아가는 다른 앱도 닫아 주세요.

업데이트 후 화면이나 기능이 이상합니다

먼저 iOS를 업데이트하고(설정 → 일반 → 소프트웨어 업데이트), 그다음 앱을 업데이트하세요. 오래된 iOS와 새 빌드의 조합은 레이아웃이 깨지거나 기능이 어긋나는 흔한 원인입니다.
