Zafe 개인 사진 보관함으로 할 수 있는 일

사진, 동영상, 파일, 메모를 Face ID와 비밀번호 보호 백업으로 기기 안에서 안전하게 보관하세요.

무료 버전에는 앨범 1개, 최대 10개 항목, Secure Notes, 자동 잠금, Face ID 또는 암호가 포함됩니다.

Pro는 한 번의 구매로 사용할 수 있습니다.

주요 기능

  • 앨범과 항목을 무제한으로 보관
  • 전용 암호로 여는 보조 안전 금고(데코이 금고)
  • 침입자 캡처는 기본적으로 꺼져 있으며, 사용자가 명시적으로 켜고 카메라 권한을 허용한 경우에만 잘못된 암호 입력 시 사진, 시간, 선택적 위치를 기록
  • 모두 Zafe 브랜드가 명확히 표시된 대체 앱 아이콘
