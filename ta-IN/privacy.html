Zafe தனியுரிமைக் கொள்கை

Face ID மற்றும் கடவுச்சொல் பாதுகாப்புள்ள backup மூலம் படங்கள், வீடியோக்கள், கோப்புகள், குறிப்புகளை சாதனத்தில் பாதுகாக்கவும்.

பாதுகாப்பு

மீடியா, கோப்பு மற்றும் குறிப்பு உள்ளடக்க data (payload), thumbnails ஆகியவை சாதனத்தில் CryptoKit AES-GCM மூலம் encrypt செய்யப்படுகின்றன. பெயர், அசல் filename, தேதி, விருப்ப coordinates போன்ற SwiftData metadataவை iOS Data Protection பாதுகாக்கிறது; இது app-level AES encryption என விவரிக்கப்படாது.

வாங்குதல்கள்

Zafeக்கு developer-operated server இல்லை (no developer-operated server). Pro access சரிபார்க்கும்போது அல்லது purchase screen திறந்து வாங்கும்போது அல்லது restore செய்யும்போது Apple StoreKit உள்ளூர் விலை மற்றும் entitlementக்காக product ID, storefront, purchase/restore transaction data பெறுகிறது. Apple தனது policyப்படி வைத்திருக்கும். Zafe local entitlement state மட்டுமே வைத்திருக்கும்; developerக்கு card details கிடைக்காது, இந்த data பகிரப்படாது.

இருப்பிடம்

Intruder camera மற்றும் location இயல்பாக off; ஒவ்வொன்றுக்கும் தனி explicit opt-in வேண்டும். Capture இயக்கிய பிறகு optional location iOS Location Services coordinatesஐ local logல் சேர்க்கிறது. Location உள்ள entryயை பார்க்கும்போது CLGeocoder place label பெற coordinatesஐ Appleக்கு அனுப்புகிறது. Open in Maps அழுத்தினால் மட்டுமே Apple Maps தேர்ந்த coordinatesஐ பெறுகிறது. Entry அல்லது app delete செய்யும் வரை அவை local SwiftDataவில் இருக்கும்; developer-operated server அல்லது பிறருக்கு அனுப்பப்படாது.

மூன்றாம் தரப்பினர்

Zafeல் account, ads, analytics அல்லது tracking இல்லை; private browser, embedded web content, remote config, VPN அல்லது NetworkExtension கூட இல்லை.

உங்கள் தரவு எங்கே இருக்கிறது

Vault items, thumbnails, SwiftData metadata மற்றும் optional intruder records தேவை இருக்கும் வரை local ஆக இருக்கும். Items, logs நீக்குவது உங்கள் கட்டுப்பாட்டில்; export செய்த backup சேமித்த இடத்திலேயே இருக்கும். Apple-service dataவை Apple தனது policyப்படி வைத்திருக்கும், developer அல்ல.
