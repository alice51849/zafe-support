Zafe ಗೌಪ್ಯತಾ ನೀತಿ

Face ID ಮತ್ತು ಪಾಸ್‌ವರ್ಡ್ ರಕ್ಷಿತ backup ಮೂಲಕ ಫೋಟೋ, ವೀಡಿಯೊ, ಫೈಲ್ ಮತ್ತು ಟಿಪ್ಪಣಿಗಳನ್ನು ಸಾಧನದಲ್ಲೇ ರಕ್ಷಿಸಿ.

ಭದ್ರತೆ

ಮೀಡಿಯಾ, ಫೈಲ್ ಮತ್ತು ಟಿಪ್ಪಣಿಗಳ ಮೂಲ data (payload) ಹಾಗೂ thumbnailಗಳನ್ನು ಸಾಧನದಲ್ಲೇ CryptoKit AES-GCM ಮೂಲಕ ಎನ್ಕ್ರಿಪ್ಟ್ ಮಾಡಲಾಗುತ್ತದೆ. ಹೆಸರು, ಮೂಲ filename, ದಿನಾಂಕ ಮತ್ತು ಐಚ್ಛಿಕ coordinates ಮುಂತಾದ SwiftData metadataಗೆ iOS Data Protection ರಕ್ಷಣೆ ನೀಡುತ್ತದೆ; ಅದನ್ನು app-level AES encryption ಎಂದು ಹೇಳುವುದಿಲ್ಲ.

ಖರೀದಿಗಳು

Zafeಗೆ developer-operated server ಇಲ್ಲ (no developer-operated server). Pro access ಪರಿಶೀಲಿಸುವಾಗ ಅಥವಾ purchase screen ತೆರೆಯುವಾಗ, ಖರೀದಿಸುವಾಗ ಅಥವಾ restore ಮಾಡುವಾಗ Apple StoreKit ಸ್ಥಳೀಯ ಬೆಲೆ ಮತ್ತು entitlementಗಾಗಿ product ID, storefront ಹಾಗೂ purchase/restore transaction data ಪಡೆಯುತ್ತದೆ. Apple ತನ್ನ ನೀತಿಯಂತೆ ಅದನ್ನು ಉಳಿಸುತ್ತದೆ. Zafe ಸ್ಥಳೀಯ entitlement state ಮಾತ್ರ ಇಡುತ್ತದೆ; developerಗೆ card details ಸಿಗುವುದಿಲ್ಲ ಮತ್ತು ಈ data ಹಂಚಲಾಗುವುದಿಲ್ಲ.

ಸ್ಥಳ

Intruder camera ಮತ್ತು location default ಆಗಿ off ಆಗಿವೆ ಮತ್ತು ಪ್ರತಿ ಒಂದಕ್ಕೂ ಪ್ರತ್ಯೇಕ explicit opt-in ಬೇಕು. Capture ಸಕ್ರಿಯವಾದ ನಂತರ optional location iOS Location Servicesನಿಂದ coordinates ಪಡೆದು ಸ್ಥಳೀಯ logಗೆ ಸೇರಿಸುತ್ತದೆ. Location ಇರುವ entry ನೋಡಿದಾಗ CLGeocoder coordinatesನ್ನು Appleಗೆ ಕಳುಹಿಸಿ place label ಪಡೆಯುತ್ತದೆ. Open in Maps ಒತ್ತಿದಾಗ ಮಾತ್ರ Apple Maps ಆಯ್ದ coordinates ಪಡೆಯುತ್ತದೆ. Entry ಅಥವಾ app ಅಳಿಸುವವರೆಗೆ ಅವು ಸ್ಥಳೀಯ SwiftDataದಲ್ಲಿ ಇರುತ್ತವೆ; developer-operated server ಅಥವಾ ಇತರರಿಗೆ ಹೋಗುವುದಿಲ್ಲ.

ಮೂರನೇ ವ್ಯಕ್ತಿಗಳು

Zafeನಲ್ಲಿ account, ads, analytics ಅಥವಾ tracking ಇಲ್ಲ; private browser, embedded web content, remote config, VPN ಅಥವಾ NetworkExtension ಕೂಡ ಇಲ್ಲ.

ನಿಮ್ಮ ಮಾಹಿತಿ ಎಲ್ಲಿ ಉಳಿಯುತ್ತದೆ

Vault items, thumbnails, SwiftData metadata ಮತ್ತು optional intruder records ಅಗತ್ಯವಿರುವವರೆಗೆ ಸ್ಥಳೀಯವಾಗಿರುತ್ತವೆ. Items ಮತ್ತು logs ಅಳಿಸುವುದು ನಿಮ್ಮ ನಿಯಂತ್ರಣದಲ್ಲಿ; export ಮಾಡಿದ backup ನೀವು ಉಳಿಸಿದಲ್ಲೇ ಇರುತ್ತದೆ. Apple-service dataವನ್ನು Apple ತನ್ನ ನೀತಿಯಂತೆ ಉಳಿಸುತ್ತದೆ, developer ಅಲ್ಲ.
