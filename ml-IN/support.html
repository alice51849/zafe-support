Zafe സഹായം

Face IDയും പാസ്‌വേഡ് സംരക്ഷിത backupഉം ഉപയോഗിച്ച് ഫോട്ടോ, വീഡിയോ, ഫയൽ, കുറിപ്പുകൾ ഉപകരണത്തിൽ സംരക്ഷിക്കുക.

സുരക്ഷ

മീഡിയ, ഫയൽ, കുറിപ്പ് എന്നിവയുടെ മൂല data (payload), thumbnailകൾ എന്നിവ ഉപകരണത്തിൽ CryptoKit AES-GCM ഉപയോഗിച്ച് എൻക്രിപ്റ്റ് ചെയ്യുന്നു. പേര്, യഥാർത്ഥ filename, തീയതി, ഐച്ഛിക coordinates തുടങ്ങിയ SwiftData metadataയെ iOS Data Protection സംരക്ഷിക്കുന്നു; അതിനെ app-level AES encryption എന്ന് വിശേഷിപ്പിക്കുന്നില്ല.

വാങ്ങലുകൾ

Zafeയ്ക്ക് developer-operated server ഇല്ല (no developer-operated server). Pro access പരിശോധിക്കുമ്പോഴും purchase screen തുറക്കുമ്പോഴും വാങ്ങുകയോ restore ചെയ്യുകയോ ചെയ്യുമ്പോഴും Apple StoreKit പ്രാദേശിക വിലയും entitlementഉം കൈകാര്യം ചെയ്യാൻ product ID, storefront, purchase/restore transaction data എന്നിവ സ്വീകരിക്കുന്നു. Apple സ്വന്തം നയപ്രകാരം അത് സൂക്ഷിക്കുന്നു. Zafe local entitlement state മാത്രം സൂക്ഷിക്കുന്നു; developerക്ക് card details ലഭിക്കുകയോ ഈ data പങ്കിടുകയോ ഇല്ല.

സ്ഥാനം

Intruder cameraയും locationഉം default ആയി off ആണ്; ഓരോന്നിനും പ്രത്യേക explicit opt-in വേണം. Capture പ്രവർത്തനക്ഷമമാക്കിയ ശേഷം optional location iOS Location Servicesൽ നിന്ന് coordinates എടുത്ത് local logൽ ചേർക്കുന്നു. Location ഉള്ള entry തുറക്കുമ്പോൾ CLGeocoder place label ലഭിക്കാൻ coordinates Appleലേക്ക് അയയ്ക്കുന്നു. Open in Maps അമർത്തിയാൽ മാത്രമാണ് Apple Maps അവ സ്വീകരിക്കുന്നത്. Entry അല്ലെങ്കിൽ app ഇല്ലാതാക്കുന്നതുവരെ coordinates local SwiftDataയിൽ തുടരും; developer-operated serverലേക്കോ മറ്റാർക്കുമോ അയയ്ക്കില്ല.

മൂന്നാം കക്ഷികൾ

Zafeയിൽ account, ads, analytics, tracking എന്നിവയില്ല; private browser, embedded web content, remote config, VPN, NetworkExtension എന്നിവയും ഇല്ല.

നിങ്ങളുടെ വിവരങ്ങൾ എവിടെ നിൽക്കുന്നു

Vault items, thumbnails, SwiftData metadata, optional intruder records എന്നിവ ആവശ്യമായിടത്തോളം local ആയി തുടരും. Items, logs എന്നിവയുടെ deletion നിങ്ങളുടെ നിയന്ത്രണത്തിലാണ്; export ചെയ്ത backup നിങ്ങൾ സൂക്ഷിച്ചിടത്ത് തുടരും. Apple-service data Apple സ്വന്തം നയപ്രകാരം സൂക്ഷിക്കുന്നു, developer അല്ല.
